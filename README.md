# CZSL Method Reproductions (Compositional Zero-Shot Learning Reproductions)

Author: **Yyitan** (GitHub: [@Yyitan](https://github.com/Yyitan))

This is a systematic collection of reproductions of multiple mainstream **Compositional Zero-Shot Learning (CZSL)** methods from the author's first year of graduate study. The goal is to establish **reliable, comparable experimental baselines** for subsequent research: the same data (MIT-States / UT-Zappos / C-GQA) and the same closed-world and open-world evaluation protocols, with each method first aligned to its paper-reported metrics before improvement experiments are built on top.

**Nature of this repository**: it contains **only documentation, reproduction notes, and upstream license texts** — no third-party code is included. All code points to the official repositories of the respective methods, and reproduction is done in separate local directories. The full notes for each method are in the [`notes/`](notes/) directory, and the upstream license texts are in the [`licenses/`](licenses/) directory.

## Method Notes

### 1. Troika (CVPR 2024) — Core Baseline

- **Key idea**: multi-path cross-modal traction on CLIP ViT-L/14 — attribute/object/composition three-path disentanglement + CMT cross-modal interaction + feature augmentation; open-world evaluation uses DFSP-style feasibility calibration.
- **Reproduction notes**: Python 3.7 + PyTorch (cu113); CLIP weights `ViT-L-14.pt` must be downloaded manually; data `mit-states / ut-zappos / cgqa`; `config/troika/<dataset>.yml` provides the full set of hyperparameters; closed/open-world are evaluated with `<dataset>.yml` and `<dataset>-ow.yml` respectively.
- **Upstream**: <https://github.com/bighuang624/troika> (MIT, see [`licenses/troika-LICENSE`](licenses/troika-LICENSE))
- **Notes**: [`notes/troika.md`](notes/troika.md)
- Acknowledgement citation (BibTeX):

### 2. CAILA (WACV 2024)

- **Key idea**: concept-aware intra-layer adapters that inject compositional concept priors into CLIP's adapter layers; the official release provides four sets of checkpoints (AUC Base/Large) for MIT-States / C-GQA / UT-Zappos / VAW-CZSL.
- **Reproduction notes**: Python 3.8 + PyTorch 1.13, `torchrun` multi-GPU training; CLIP weights ViT-B/32 and ViT-L/14 taken from HuggingFace; the data directory layout and `DATA_FOLDER` in `flags.py` must be configured per the official conventions.
- **Upstream**: <https://github.com/zhaohengz/CAILA> (MIT, see [`licenses/caila-LICENSE`](licenses/caila-LICENSE))
- **Notes**: [`notes/caila.md`](notes/caila.md)

### 3. PLID (ECCV 2024)

- **Key idea**: built on CLIP, uses an LLM (OPT-1.5B by default) to generate language-rich descriptions and constructs diverse prompts in the form of Gaussian distributions (language-informed distribution); supports closed-world and open-world.
- **Reproduction notes**: Python 3.7 + CLIP; besides the raw data, it requires the LLM text features (`opt_xxx.pkl`) and GloVe feasibility scores provided via the upstream Gdrive; training/evaluation scripts are under `exp/<dataset>/`.
- **Upstream**: <https://github.com/Cogito2012/PLID> (BSD-3-Clause, see [`licenses/plid-LICENSE`](licenses/plid-LICENSE))
- **Notes**: [`notes/plid.md`](notes/plid.md)

### 4. FlowComposer + Troika (CVPR 2026, self-built reproduction)

- **Key idea**: brings rectified flow into CZSL — primitive flows for the attribute/object paths (MAR/DiT-style adaLN residual MLPs), a Composer predicting composition coefficients (least-squares closed-form target), leakage-guided augmentation, and one-step transport `x_hat_c1 = x0^c + h * v_hat_c`; mounted on top of Troika's three-path branches.
- **Reproduction notes**: same environment as Troika; at `flow_depth: 24` each flow adds roughly +70M parameters (+150–170M in total); on OOM, reduce `flow_depth` / `flow_hidden_dim`. The notes record three implementation decisions the paper leaves unspecified (sources of the x0/x1 features, the fused scoring formula, and detaching the Composer input).
- **Upstream**: paper [arXiv:2603.16641](https://arxiv.org/abs/2603.16641) (no official code found); baseline Troika [bighuang624/troika](https://github.com/bighuang624/troika) (MIT)
- **Notes**: [`notes/flowcomposer-troika.md`](notes/flowcomposer-troika.md)

### 5. H2EM (arXiv, self-built reproduction based on Troika)

- **Key idea**: hierarchical hyperbolic embeddings — replacing Troika's Euclidean CMT with hyperbolic cross-modal attention HCA (Lorentz manifold, learnable curvature), extending the text branch to 5 classes (including an LLM-generated parent semantic tree), with loss = discriminative alignment L_DA + classification entailment L_TE + primitive auxiliary L_aux.
- **Reproduction notes**: same environment as Troika; ~14.6M trainable parameters; the semantic tree is generated offline by rules (`build_taxonomy.py`), replacing the paper's Gemini-2.5 Pro with zero external dependencies; closed-world is fully usable, UT-Zappos open-world runs, and MIT/CGQA open-world requires a chunked text-first path (see "Known limitations" in the notes).
- **Upstream**: paper [arXiv:2512.20029](https://arxiv.org/abs/2512.20029) (no official code found); baseline Troika [bighuang624/troika](https://github.com/bighuang624/troika) (MIT)
- **Notes**: [`notes/h2em.md`](notes/h2em.md)

### 6. ar-classifier (ECCV 2026, adjacent direction)

- **Key idea**: revisiting visual autoregressive generative classifiers — using any-order AR (RandAR) to predict and marginalize over multiple token orderings, outperforming diffusion classifiers (DiT/SiT) while saving up to 25× compute.
- **Reproduction notes**: conda env `genclass` (`python<3.10`, `pytorch=1.12.1`, timm/accelerate/diffusers, etc.); requires `git clone --recursive` to pull the DiT / SiT / RandAR submodules; official checkpoints on HuggingFace at [iasudakov/ar_classifier](https://huggingface.co/iasudakov/ar_classifier); evaluation needs ImageNet val and imagenet-X, with `--n_trials` / `--step_size` / `--n_samples` to control the cost.
- **Upstream**: <https://github.com/iasudakov/ar-classifier> (paper [arXiv:2603.19122](https://arxiv.org/abs/2603.19122))
- **Notes**: [`notes/ar-classifier.md`](notes/ar-classifier.md)
